# sesac-web

새싹캠퍼스 파이썬 과정에서 만든 첫 웹페이지입니다.

## 1. 무엇을 만들었나요

공공데이터를 파이썬으로 분석하고, 그 결과를 웹페이지로 만들어 인터넷에 공개한 프로젝트입니다. 페이지는 세 부분입니다. 맨 위는 만든 사람을 소개하는 짧은 글과 표입니다. 두 번째는 노원구 아파트 매매 거래 7,190건을 분석해 평균 거래가(약 6.5억 원)와 최고가 상위 5건을 보여줍니다. 세 번째는 장기요양보험 급여를 지역별로 비교한 결과인데, 노인 1인당 급여가 가장 높은 충청북도(185만 원)와 가장 낮은 부산광역시(106만 원) 사이에 1.75배 차이가 나고, 그 차이가 고령화율만으로는 설명되지 않는다는 점을 보여줍니다.

## 2. 파일 구성과 만든 과정

### 이 저장소에 있는 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 전체. 자기소개와 두 가지 분석 결과가 한 파일에 들어 있습니다 |
| `analyze.py` | 아파트 실거래 분석 코드 (파이썬 표준 라이브러리만 사용) |
| `analyze_ltc.py` | 장기요양보험 급여 분석 코드 (pandas 필요) |
| `README.md` | 지금 읽고 계신 문서입니다 |

페이지는 HTML 파일 하나로만 되어 있습니다. CSS는 `<style>` 태그 안에 함께 넣어서 따로 관리할 파일이 없습니다.

### 만든 과정

1. **페이지 뼈대 만들기** — 이름, 소개 문단, 표가 있는 `index.html`을 작성했습니다
2. **브라우저로 확인하고 고치기** — 파일을 열어 보면서 소개 내용을 직접 다듬었습니다
3. **데이터 분석하기** — 서울시 아파트 실거래 CSV를 읽어 노원구의 평균 거래가와 거래 건수, 그리고 최고가 상위 5건을 뽑는 파이썬 코드(`analyze.py`)를 작성해 실행했습니다
4. **결과를 페이지에 얹기** — 3번에서 나온 숫자를 `index.html` 아래쪽에 새 섹션으로 추가했습니다
5. **GitHub에 올리기** — `git`으로 이 저장소에 올렸습니다
6. **GitHub Pages로 공개하기** — 저장소 설정에서 Pages를 켜서 누구나 접속할 수 있는 주소를 만들었습니다
7. **두 번째 데이터 얹기** — 같은 방법으로 장기요양보험 급여 데이터를 분석해(`analyze_ltc.py`) 페이지에 섹션을 하나 더 추가했습니다

### 내 컴퓨터에서 보기

저장소를 내려받아 `index.html` 파일을 더블클릭하면 기본 브라우저로 열립니다.

```bash
git clone https://github.com/JAEYONG0303/sesac-web.git
```

- Windows: 파일 탐색기에서 `index.html` 더블클릭, 또는 PowerShell에서 `start index.html`
- macOS: Finder에서 더블클릭, 또는 터미널에서 `open index.html`

서버를 띄울 필요 없이 파일만 열면 되는 정적 페이지입니다.

### 분석 코드 직접 돌려보기

**아파트 실거래** — 파이썬만 있으면 실행됩니다. 설치할 라이브러리가 없습니다.

```bash
python analyze.py          # 노원구
python analyze.py 강남구    # 다른 구가 궁금하다면
```

구 이름을 붙이면 그 구의 평균 거래가·거래 건수와 최고가 상위 5건을 보여줍니다.

**장기요양보험 급여** — 엑셀을 읽어야 해서 pandas가 필요합니다.

```bash
pip install pandas openpyxl
python analyze_ltc.py            # 서울특별시
python analyze_ltc.py 경기도      # 다른 시도가 궁금하다면
```

시도 이름을 붙이면 그 지역의 공단부담금·수급자 수·노인 1인당 급여와, 노인 1인당 급여 상위 5개 시도를 보여줍니다.

단, 원본 데이터 파일은 용량이 크거나 가공 과정이 필요해서 이 저장소에 올리지 않았습니다. `data/` 폴더를 만들어 넣으면 동작합니다.

## 4. 데이터 출처

### 서울 아파트 실거래

- **출처**: [서울열린데이터광장](https://data.seoul.go.kr) — 서울시 부동산 실거래가 정보 (OA-21275)
- **기간**: 2025년 7월 ~ 2026년 6월
- **범위**: 서울시 아파트 **매매** 거래 (전세·월세 거래는 분석에서 제외했습니다)
- **금액 단위**: 원본 데이터의 금액은 만원 단위입니다. 예를 들어 `156,000`은 15억 6천만 원을 뜻합니다

페이지에 실린 노원구 통계는 위 기간의 매매 거래 7,190건을 집계한 것입니다.

### 장기요양보험 급여

- **출처**: 국민건강보험공단 「장기요양보험 통계연보」 3-1표(급여 실적)와 통계청 인구·지역내총생산 자료
- **기간**: 2010년 ~ 2024년
- **단위**: 17개 시도 × 15년 패널. 금액은 물가 영향을 걷어낸 **2024년 불변가격** 기준입니다
- **지표**: 공단부담금(건강보험공단이 부담한 금액)을 65세 이상 인구로 나눈 값을 "노인 1인당 급여"로 썼습니다

지역 간 비교에 총액이 아니라 1인당 금액을 쓴 이유는, 인구가 많은 지역은 총액도 자연히 커지기 때문입니다.
