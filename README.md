# 장기요양보험 급여 대시보드

> 2010~2024년 장기요양보험 공단부담금을 지역·시간·서비스 구조 세 축으로 살펴보는 인터랙티브 대시보드

**보러 가기 → https://jaeyong0303.github.io/sesac-web/**

## 1. 무엇을 만들었나요

장기요양보험 급여는 2010년 3.2조 원에서 2024년 14.8조 원으로 **4.7배** 커졌습니다. 규모가 커졌다는 사실은 알려져 있지만, 그 돈이 어느 지역에 어떤 형태로 쓰였는지는 잘 정리되어 있지 않습니다. 이 대시보드는 국민건강보험공단이 공개한 통계연보 한 벌을 끝까지 파고들어, 세 가지 질문에 답합니다. 어느 지역이 많이 쓰고 적게 쓰는지, 15년 동안 어떤 속도로 커졌는지, 그리고 서비스 구조가 어떻게 바뀌었는지입니다. 처음 보는 사람도 3분이면 세 가지 흐름을 파악할 수 있도록 만들었고, 데이터의 한계도 숨기지 않고 함께 적어 두었습니다.

## 2. 파일 구성과 만든 과정

### 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 대시보드 화면 구조 |
| `styles.css` | 스타일 (다크모드·반응형 포함) |
| `app.js` | 데이터 로드, 차트 생성, 인터랙션 |
| `data.json` | 대시보드가 읽는 데이터 (69KB) |
| `prepare_data.py` | 원본 엑셀 → `data.json` 변환 스크립트 |
| `PRD.md` | 기획 문서. 무엇을 왜 만들었는지 |

### 만든 과정

1. **데이터 파악** — 원본 엑셀의 시트 8개와 변수 38개를 훑고, "쓰면 안 되는 것" 목록(분모 함정, 합산 불가 항목 등)을 먼저 정리했습니다
2. **기획** — 페르소나와 핵심 질문 3개를 정하고 화면 구성·시각화·한계 명시 방침을 `PRD.md`에 확정했습니다
3. **데이터 가공** — `prepare_data.py`로 필요한 지표만 뽑아 가벼운 JSON으로 만들었습니다. 브라우저에서 엑셀을 직접 읽지 않아도 되도록 한 것입니다
4. **구현** — 빌드 도구 없이 HTML/CSS/JS와 ECharts만으로 8개 차트를 만들었습니다
5. **검증** — 로컬 서버로 띄워 KPI 값, 결측 처리, 인터랙션 연동, 375px 반응형, 다크모드, 콘솔 에러를 하나씩 확인했습니다
6. **배포** — GitHub Pages로 공개했습니다

### 화면 구성

- **KPI 스트립** — 총급여·노인 1인당 급여·수급률·재가 비중 (모두 데이터에서 실시간 계산)
- **1. 지역 격차** — 카토그램 지도 + 순위 막대 + 산점도. 지표 5종 전환, 연도 슬라이더(재생 가능), 시도 선택이 서로 연동됩니다
- **2. 시간의 변화** — 전국 추이, 시도별 궤적, 성장 배수
- **3. 구조 전환** — 재가/시설 비중, 등급 구성, 시도별 재가 비중 이동(덤벨)
- **그래서 무엇을 알 수 있나** — 차트에서 읽어낸 결론 3가지. 숫자는 모두 실시간 계산합니다
- **한계와 주의사항** — 접이식 섹션

## 3. 어떻게 보나요

### 인터넷에서 보기

**https://jaeyong0303.github.io/sesac-web/** — 설치나 로그인 없이 바로 열립니다. 휴대폰에서도 동작합니다.

### 내 컴퓨터에서 보기

`fetch`로 `data.json`을 읽기 때문에 파일을 더블클릭하면 브라우저 보안 정책에 막힙니다. 간단한 서버를 하나 띄워야 합니다.

```bash
git clone https://github.com/JAEYONG0303/sesac-web.git
cd sesac-web
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000` 으로 접속하면 됩니다.

### 데이터를 새로 만들려면

원본 엑셀이 있을 때만 필요한 단계입니다. 엑셀을 `data/` 폴더에 넣고 실행하면 `data.json`이 다시 만들어집니다.

```bash
pip install pandas openpyxl
python prepare_data.py
```

## 4. 데이터 출처

- **출처**: 국민건강보험공단 「장기요양보험 통계연보」 3-1표(시·군·구별 등급별 급여종류별 급여실적), 통계청 인구 자료
- **기간**: 2010년 ~ 2024년 (15년)
- **범위**: 17개 시도. 시군구 자료도 있지만 인구·GRDP가 없어 1인당 지표를 만들 수 없어 제외했습니다
- **금액**: 공단부담금 기준. **2024년 불변가격**으로 실질화해 물가 영향을 제거했습니다
- **집계 기준**: 수급자 주민등록주소지 기준(연도말), 전 기간 통일

### 읽으실 때 주의할 점

- **인과관계를 주장하지 않습니다.** 제도 변화 시점을 차트에 표시했지만, 그 시점 이후의 변화가 제도 때문이라고 말하지 않습니다
- **수급자 수는 중복배제된 값**이라 지역 간 합산이 성립하지 않습니다. 그래서 전국 수급률도 합계가 아니라 **시도별 비율의 중앙값**으로 계산했습니다
- **노인 1인당 지표**는 지역 규모를 보정해 주지만, 분모인 노인인구가 지역마다 다른 속도로 변해 왔습니다. 시점 간 비교에는 주의가 필요합니다
- **세종특별자치시는 2012년 출범**이라 그 이전 데이터가 없고, 2012년 인구도 결측입니다. 차트에서는 0이 아니라 "자료 없음"으로 처리했습니다
